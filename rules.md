# Жесткие правила разработки и архитектуры проекта (AppSeaPro Agency)

Данный документ является **категорической инструкцией** для любого ИИ-агента или разработчика, работающего с кодовой базой сайта-бутика **AppSeaPro Agency**. Нарушение этих правил ведет к поломке интерфейса, нарушению авторского визуального стиля и сбоям сборки.

---

## 1. Фундаментальные правила работы (Golden Rules)

1. **Строго целевая работа:** Делать СТРОГО ТОЛЬКО ту задачу, о которой просит пользователь в конкретном сообщении.
2. **Категорический запрет на «улучшайзинг»:** ЗАПРЕЩЕНО самостоятельно менять, удалять, «рефакторить», стилизовать по-новому или переписывать соседние компоненты, стили, анимации и файлы, не относящиеся к задаче напрямую.
3. **Хирургическая точность:** Править только конкретные строки кода, не переписывая файл целиком, если в этом нет технической необходимости.
4. **Язык общения:** Общаться с пользователем ТОЛЬКО на простом и доступном русском языке, без нагромождения сложного академического сленга.
5. **Безопасность команд в терминале:** Перед запуском любой команды, требующей подтверждения (Submit), сначала кратко объяснить пользователю на русском языке, что делает команда и почему её запуск безопасен.

---

## 2. Стек технологий и фреймворки

- **Категорический запрет на TypeScript:**
  - Проект пишется **исключительно на современном JavaScript (ES6+)**.
  - Все компоненты должны иметь расширение `.jsx`, а вспомогательные скрипты и хуки — `.js`.
  - **СТРОГО ЗАПРЕЩЕНО** генерировать типизацию, интерфейсы, `type`/`interface` и создавать файлы с расширениями `.ts` или `.tsx`.
- **Next.js 16 (App Router):** 
  - Используется статическая генерация (`output: 'export'` в `next.config.mjs`).
  - Все картинки имеют настройку `images: { unoptimized: true }` (для корректного статического экспорта на хостинг/GitHub Pages).
  - **Ограничения бэкенда и сбор данных:** 
    - **ЗАПРЕЩЕНО** использовать Server Actions, Node.js API Routes, SSR-запросы к базам данных и серверные обработчики. Сборка должна гарантированно компилироваться в статический каталог `out/`.
    - Для сбора лидов, отправки контактных форм или бронирований использовать **только клиентский `fetch` к вебхукам Google Apps Script** или прямую клиентскую **интеграцию с Firebase**.
- **React 19:**
  - Все интерактивные компоненты обязаны содержать директиву `"use client";` на первой строке.
- **Tailwind CSS v4:**
  - Подключен через `@import "tailwindcss";` в `src/app/globals.css`.
  - В проекте нет и **не должно быть** `tailwind.config.js` (конфигурация v4).
  - **ЗАПРЕЩЕНО** устанавливать и подключать внешние UI-библиотеки (Shadcn, MUI, Ant Design, Chakra UI, Bootstrap) или CSS-in-JS (Styled-Components, Emotion). Вся стилизация пишется исключительно классами Tailwind и базовыми классами из `globals.css`.
- **Типографика (Google Fonts через next/font/google):**
  - Sans-шрифт: **Inter** (`--font-sans`).
  - Serif-шрифт: **Playfair Display** (`--font-serif`, начертания normal и italic). Используется для заголовков и акцентных цитат (`font-serif`, `italic`).

## 3. Библиотеки иконок: КАТЕГОРИЧЕСКИЙ ЗАПРЕТ

- **ЗАПРЕЩЕНО устанавливать внешние пакеты иконок:**
  - Никаких `npm install lucide-react`, `react-icons`, `@heroicons/react`, `font-awesome` и т.д.! В зависимостях их нет, и добавлять их нельзя.
- **Стандарт иконок проекта — только чистый инлайн SVG:**
  - Все иконки верстаются инлайновым тегом `<svg viewBox="0 0 24 24" ...>...</svg>`.
  - Стандартные контурные иконки: `fill="none" stroke="currentColor" strokeWidth="1.5"` (или `strokeWidth="1.75"` / `strokeWidth="2"`).
  - Брендовые/мессенджерные иконки (Telegram и др.): `fill-current`.
  - Размеры строго через классы Tailwind (`w-4 h-4`, `w-5 h-5`, `w-6 h-6`).

## 4. Архитектура и структура директорий

Код строго структурирован по назначению в папке `src/`:

```
src/
├── app/                  # Корневые файлы App Router
│   ├── layout.js         # Главный HTML-каркас, метаданные, JSON-LD, подключение шрифтов
│   ├── page.jsx          # Главная страница (дирижер состояний, модалок и порядка секций)
│   ├── globals.css       # Глобальные стили, анимации, стили кастомного курсора и стекла
│   ├── robots.js         # SEO правила для поисковиков
│   └── sitemap.js        # Карта сайта
├── components/           # UI-компоненты
│   ├── layout/           # Общий каркас интерфейса (Header.jsx, Footer.jsx, MobileMenu.jsx)
│   ├── sections/         # Независимые секции страницы (HeroSection, Showroom, PricingSection, AboutSection, ReviewsSection, FaqSection, TechSection)
│   └── modals/           # Модальные окна (BeautyModal, HorecaModal, InfinityModal)
├── data/                 # Статические данные, оторванные от верстки (pricingPlans.js, horecaConfig.js, infinityTemplates.js)
└── hooks/                # Кастомная логика и хуки (useHeroTilt.js, useCustomCursor.js, useCardAudio.js и т.д.)
```

### Правила структурирования кода:
1. **Данные отдельно от верстки:** Тексты тарифов, списки ниш, конфигурации демо-модалок выносятся в `src/data/`. Не зашивать простыни статических данных прямо внутрь JSX секций.
2. **Модальные окна:** 
   - Рендерятся строго через `createPortal(..., document.body)`.
   - Обязательно блокируют прокрутку страницы при открытии (`document.body.style.overflow = 'hidden'`) и восстанавливают при закрытии.
   - Обязательно поддерживают закрытие по клавише `Escape` и клику на оверлей.
3. **Безопасные зоны мобильных экранов:**
   - Для фиксированных шапок, футеров и плавающих кнопок обязательно использовать `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`.

## 5. Фирменная дизайн-система и визуальный стиль

Стиль проекта — **«Тихая роскошь» (Dark Glassmorphism & Quiet Luxury)**: глубокий угольный фон, матовые стекла с подсветкой курсора, градиентные переливы, минималистичные неоновые акценты.

### Палитра цветов (Строго фиксирована):
- **Основной фон сайта:** `#050505` (глубокий угольный черный). Белый или серый сплошной фон страницы запрещен.
- **Фон карточек и инпутов:** `#121212`, полупрозрачные темные слои (`bg-black/60`, `bg-white/[0.02]` — `bg-white/[0.07]`).
- **Основной текст:** `#F3F4F6` (мягкий белый) и `text-white`.
- **Второстепенный текст:** `#D4D4D8` (нейтральный серебристый) и `#A1A1AA` (приглушенный серый).
- **Фирменный акцентный цвет (Carmine / Wine):** `#E50940`
  - Используется для логотипа `AppSea<span className="text-[#E50940] italic">Pro</span>`, пульсирующих точек, бейджей, тонких линий-акцентов и фонового свечения `.bg-glow.wine`.
- **Границы и разделители:** Полупрозрачный белый: `border-white/5`, `border-white/10`, `border-white/15`, `border-white/20`.
- **Текстовый градиент заголовков:**
  ```jsx
  <span className="italic text-transparent bg-clip-text bg-gradient-to-r from-white to-[#D4D4D8]">
    Акцентное Слово
  </span>
  ```

### Фирменные CSS-классы:
- `.glass-card` — базовое темное матовое стекло с блюром и рамкой.
- `.luxury-subcard` — вложенные премиальные блоки со скруглением `rounded-2xl`.

## 6. Интерактивность и UI

- **Локализация и языковые переключатели:**
  - Для армянского языка в любых языковых переключателях и локализации **ВСЕГДА использовать код `HY`** (использование `AM` строго запрещено).
- **Интерактивные элементы и кастомный курсор (`.interactive-elem`):**
  - **ОБЯЗАТЕЛЬНЫЙ класс** для всех интерактивных элементов (кнопки, ссылки, карточки, инпуты, переключатели), чтобы кастомный курсор `.custom-cursor` плавно расширялся и реагировал при наведении.
- **Кнопки (Buttons UI):**
  - **Главное целевое действие (Primary CTA):** Белая таблетка с черным текстом и мягким свечением:
    `rounded-full bg-white text-black font-medium px-6 py-3 hover:bg-gray-200 transition-colors shadow-[0_0_15px_rgba(255,255,255,0.2)] cursor-pointer`
  - **Второстепенное действие (Secondary Glass):** Стеклянная пилюля с тонкой рамкой:
    `rounded-full bg-white/[0.04] backdrop-blur-md border border-white/10 text-xs sm:text-sm text-[#D4D4D8] hover:text-white hover:bg-white/[0.09] hover:border-white/25 transition-all`

## 7. Анимации и UI-паттерны

- **Тактильный отклик (Vibration API):**
  - При создании важных мобильных интеракций (переключатели, свайпы, подтверждения) использовать Vibration API (`navigator.vibrate`) для легкого тактильного отклика (с безопасной проверкой `typeof navigator !== 'undefined' && navigator.vibrate`).
- **Стеклянные карточки (`.glass-card`):**
  - Фирменное стекло: `backdrop-filter: blur(28px)`, рамка `1px solid rgba(255, 255, 255, 0.1)`, скругление `rounded-[28px]` или `rounded-3xl`.
  - Внутренний контейнер карточки обязательно оборачивать в `<div className="glass-content">...</div>`.
  - Элемент с карточкой должен содержать обработчики `onMouseMove={onGlassMove}` и `onTouchMove={onGlassMove}` для перемещения светового блика за курсором.
- **Вложенные подкарточки (`.luxury-subcard`):**
  - Вложенные премиальные стеклянные блоки внутри больших карточек (скругление `rounded-2xl`).
- **Элементы появления и фоновые свечения:**
  - `.fade-up-elem` — для элементов, проявляющихся при прокрутке.
  - `.bg-glow.wine` и `.bg-glow.cyan` — декоративные плавающие размытые шары света на фоне.
